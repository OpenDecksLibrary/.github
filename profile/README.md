# OpenDecksLibrary

An independent community initiative for building, maintaining and sharing high-quality Anki decks.

## Collections

| Project | Description | Status |
| --- | --- | --- |
| [Ultimate Hitster](https://github.com/OpenDecksLibrary/ultimate-hitster) | Music recognition and release-year recall, organized by game edition | In development |
| [Deck Builder](https://github.com/OpenDecksLibrary/deck-builder) | Shared tools for reproducible Anki deck generation | Planned |

## Our approach

- Versioned source data and reproducible builds.
- Clear documentation and transparent corrections.
- Stable note identities to support progress-preserving updates.
- Community contributions through issues and pull requests.

Deck downloads will be available through each collection's GitHub Releases once tested.

This is an independent community project, not affiliated with Anki or the games and services referenced by its collections.
